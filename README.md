# FIELDGUIDE — Special Warfare Prep

A static, browser-based fitness planning website. The main page and qualification guides can be hosted directly without a server or build step.

## Publish with GitHub Pages

1. Put the contents of this folder in a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. GitHub Pages will provide the public website address when its deployment finishes.

Keep `index.html`, `.nojekyll`, `robots.txt`, and the `qualification-guides/` folder together at the published site root so all guide links work.

The planner runs in the visitor’s browser. It does not send entered fitness scores to a server. This independent preparation resource is not an official military recruiting or medical source; verify current requirements with the relevant service.
